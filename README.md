# TrueSight-UI

TrueSight UI is a modern approach to D&D Beyond character sheets.

It acts as a lightweight visual overhaul that redesigns, reorganizes, and resizes the interface to help you find information faster during sessions.

I built this because I wanted my own character sheet to feel modern and calm, based on years of playing on D&D Beyond. This isn't random "vibe-coding" – every margin, font size, and box position was intentionally designed to fix specific UI frustrations.


// Key Features:
- Cleaner layout: Less visual clutter with optimized sizing and positioning for a modern look.
- Better readability: Tweaked fonts and contrasts for easier reading.
- Quick Links: A new custom box to save character-specific bookmarks and reference links in one accessible spot.
- Beyond 20 Support: I specifically tweaked the design of Beyond 20 to match the visual language of TrueSight UI, so both extensions look great together.
- Lightweight: 99% CSS customization – no heavy scripts, no tracking, no data collection.

// How it works:
99% of the magic is created by 1,500 lines of handwritten CSS, and only where styles alone are not enough does TrueSight UI use JavaScript to achieve its goal (like syncing the sidebar, moving passive senses and for the Quick-Links-Box).

// How to use:
1. Install the extension and navigate to your D&D Beyond character sheet. 
2. Set sheet appearance to [Underdark Mode]. 
3. Use the extension popup to toggle the visual enhancements on or off at any time.
4. ...
5. Profit.

// Community First:
This is a passion project by me – KRNKFRD. I use it in my own campaigns and am happy to share it with the community. If you like it, let me know!

// Privacy & Safety:
TrueSight UI runs entirely locally in your browser. Even your custom Quick Links are saved directly on your device and are never sent to a cloud or external server. The extension does not collect, store, or transmit any user data.
